# Personal-banking-dashboard
Tableau dashboard analyzing personal income, expenses, spending categories, and monthly savings trends.

This project presents an interactive Personal Banking Dashboard built in Tableau to analyze income, expenses, and overall financial activity. The dashboard compares monthly income and expenses, breaks down different income sources and spending categories, and summarizes total income, expenses, and net savings.
The goal of this project was to transform financial transaction data into clear visual insights that make it easier to understand spending behavior and overall financial performance.
